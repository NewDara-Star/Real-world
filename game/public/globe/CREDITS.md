# Globe images

All three are the example images shipped with the `three-globe` npm package
by Vasco Asturiano (MIT, https://github.com/vasturiano/three-globe,
`example/img/`), byte for byte.

- `earth-blue-marble.jpg`: NASA Visible Earth, Blue Marble (public domain).
- `earth-night.jpg`: NASA Visible Earth, Black Marble city lights (public domain).
- `earth-water.png`: water mask (specular map) derived from NASA imagery, from the same package.

The star background is drawn in code (`globe.ts`, `starField`), so it has no source to credit.
