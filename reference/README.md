# Reference photos

Look at photos while modelling; don't keep them. `.gitignore` refuses
everything here except this README and each asset's `preview.png` (your own
render of the finished model).

- Your own photos first. Geograph Ireland, Wikimedia Commons and Panoramax may
  be looked at for reference. Never Google Maps, Street View or Earth.
- Never trace a photo or use it as a texture.
- Model what the building or object looks like, with nothing that identifies
  it: no logos or shop names (not even Lidl, Aldi, Spar, Tesco), no house
  numbers, no number plates, no people.
